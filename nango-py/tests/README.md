# Test suites

Add tests with each vertical slice:

- `unit/`: isolated domain and application behavior.
- `contract/`: Python consumption of fixtures generated by authoritative TypeScript code.
- `integration/`: real services and migrated PostgreSQL schemas; no fake DB sessions.
- `differential/`: same scenario executed against TypeScript and Python with accepted deltas documented.

Only `unit/` exists during bootstrap. Create other directories when their first real test lands.
